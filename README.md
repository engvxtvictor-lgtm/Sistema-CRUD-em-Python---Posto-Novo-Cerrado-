### Sistema CRUD - Posto Novo Cerrado
###Descrição

### Sistema desenvolvido em Python para gerenciamento básico de um posto de combustível através do terminal.

# Funcionalidades : 
-Cadastrar clientes
-Listar clientes
-Buscar clientes
-Atualizar clientes
-Excluir clientes
-Cadastrar combustíveis
-Listar combustíveis
-Registrar vendas
-Listar vendas
-Gerar relatório de estoque e vendas

# Estrutura do Projeto :
-dados.py → armazenamento dos dados
-utils.py → funções auxiliares
-crud.py → operações do sistema
-main.py → menu principal

# Conceitos Utilizados :
-Listas
-Dicionários
-Tuplas
-Sets
-Funções
-CRUD
-Try/Except
-Yield
-List Comprehension
-Dict Comprehension
-Slicing

# Como Executar :
python main.py
